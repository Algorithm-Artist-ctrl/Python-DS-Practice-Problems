# Python Inbuilt Data Structure Practice

This repository contains a collection of Python exercises focused on practicing built-in data structures such as **lists, dictionaries, and tuples**.

Each exercise is saved in a separate file, with a clear name and commit message that describes the task. This approach keeps the repository clean and makes it easy to track progress and revisit individual problems.

---

## 🚀 Purpose

- Strengthen understanding of Python’s core data structures
- Improve problem-solving skills
- Prepare for coding interviews and assessments
- Build a reference library of common structure-based problems

---

## 📁 Structure

- Each `.py` file contains a standalone coding exercise
- Exercises focus on core operations like:
  - List manipulation
  - Dictionary merging and lookups
  - Tuple operations
  - Set comparisons
